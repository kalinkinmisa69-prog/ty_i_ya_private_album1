# «Ты и Я» — личный фотоальбом

Нежный сайт-дневник для двоих: альбомы, подписи, даты и вход по паролю.

## Важно про приватность
Этот шаблон рассчитан на публикацию в **Cloudflare Pages** с проверкой пароля на сервере (Pages Function).
Не выкладывайте фото в публичный GitHub-репозиторий. Используйте приватный репозиторий и проверьте настройки доступа к проекту.
Пароль задаётся в Cloudflare как секрет `ALBUM_PASSWORD`, а ключ подписи сессии — как секрет `SESSION_SECRET`.
Не используйте один из этих секретов в HTML/JavaScript.

## Как посмотреть сайт на компьютере
Можно просто открыть `public/index.html` для просмотра дизайна, но **локальное открытие не обеспечивает защищённый вход**.
Для работающей защиты опубликуйте проект через Cloudflare Pages, чтобы выполнялась функция `functions/_middleware.js`.

## Публикация с защитой
1. Создайте приватный репозиторий на GitHub и загрузите содержимое этой папки.
2. В Cloudflare откройте Workers & Pages → Create → Pages → Connect to Git.
3. Выберите репозиторий. Build command оставьте пустой, output directory укажите `public`.
4. В настройках Pages → Settings → Variables and Secrets добавьте:
   - `ALBUM_PASSWORD` — придуманный длинный пароль для входа в альбом.
   - `SESSION_SECRET` — длинная случайная строка, не совпадающая с паролем.
5. Опубликуйте сайт и проверьте вход в приватном окне браузера.
6. Добавляйте фото в `public/photos/` и обновляйте список альбомов в `public/script.js`.

## Как добавить фотографии
Положите снимки в `public/photos/`. Например:
- `morning-01.jpg`
- `together-01.jpg`

Затем откройте `public/script.js` и замените демонстрационные записи в массиве `albums` на свои названия, имена файлов, даты и подписи.

## Советы
- Перед загрузкой удалите фотографии, которыми не хотите делиться.
- Не используйте угадываемый пароль.
- Не отправляйте пароль вместе со ссылкой в одном сообщении.
- Этот шаблон защищает страницы и статические файлы сессионной cookie; для особо чувствительных данных рассмотрите дополнительную защиту аккаунтом/провайдером и проверьте настройки после публикации.


## Персонализация «для нас»
В `public/script.js` в начале файла найди `coupleSettings`:
- `relationshipStart` уже установлен на `2026-07-06` (06.07.2026).
- `yourNameForHer` и `herNameForYou` — ваши ласковые обращения (их можно поменять под себя).

В `public/index.html` можно изменить текст письма и секретного послания. Сейчас в тексте уже есть «радость моя», «любимка», «солнышко», «заечка» и подпись «твой Коть». Счётчик дней начнёт считать после того, как укажешь дату начала отношений.


## Общие загрузки фото (для вас обоих)
Форма загрузки в альбоме использует Cloudflare R2. Чтобы она работала:
1. В Cloudflare создайте R2 bucket, например `ty-i-ya-photos`.
2. В настройках Cloudflare Pages → Settings → Functions → R2 bucket bindings добавьте binding с именем `PHOTOS_BUCKET` и выберите созданный bucket.
3. Перепубликуйте сайт. Загруженные фотографии и подписи будут храниться в R2 и показываться обоим пользователям после входа.
4. Лимит файла в шаблоне — 8 МБ; разрешены JPG, PNG, WebP и GIF.
5. Не создавайте публичный доступ к R2 bucket: фото отдаются через защищённый API сайта.

Важно: проверьте конфигурацию и доступ к функциям перед загрузкой личных фото. Сначала протестируйте на нескольких несекретных изображениях.


При загрузке можно выбрать подпись автора: «Твой Коть ♡» или «Моя заечка ♡». Это отображается под фото; выбор сделан вручную, поэтому он не подтверждает личность вошедшего пользователя.
